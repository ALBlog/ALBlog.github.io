# 周四科技刚蹦完迪，周五就被查票：明天A股看一件事

我们结合周四的行情一起看，周四上证指数涨 `1.65%`，深证成指涨 `3.07%`，创业板指涨 `4.49%`。半导体盘中涨幅接近 `7%`，科创方向一度像集体开了加速器。

结果周五，市场突然冷静了。上证指数跌 `1.00%`，深证成指跌 `2.29%`，创业板指跌 `4.37%`，科创50更狠，跌 `5.53%`。

这两天连起来看，A股不像在走行情，像在演短剧。更有意思的是，周五成交额还不小。上证成交约 `1.56万亿`，深市成交约 `1.83万亿`，两市合计大约 `3.39万亿`。

所以这不是没人玩了。是人还在，钱还在，只是大家开始变挑了。

## 一、周五为什么砸？因为试完以后，市场开始验货

周五最关键的变化，是科技没有接住周四的强修复。

跌幅榜很有代表性：

| 周五弱势方向 |   跌幅 |
| ------------ | -----: |
| 集成电路制造 | -8.49% |
| 半导体设备   | -7.81% |
| 半导体材料   | -6.32% |
| 电子化学品   | -5.73% |
| 半导体       | -5.38% |
| 数字芯片设计 | -4.44% |
| 存储芯片     | -3.34% |
| 光通信模块   | -3.35% |
| PCB          | -3.02% |
| 证券         | -1.88% |

这张表翻译成人话就是：

**周四谁冲得最猛，周五谁先被按住检查身份证。**

半导体、芯片、光模块、PCB，全是前期资金最爱的科技线。周五不是随便跌，是精准打在高弹性科技身上。更扎心的是资金流向。

东方财富板块主力资金口径显示，周五电子板块主力净流出约 `435亿元`，半导体净流出约 `249亿元`，存储芯片净流出约 `217亿元`，科技风格净流出约 `460亿元`。这就不是“小作文吓了一下”，而是资金真的在减仓高拥挤方向。



## 二、周五谁没趴下？军工、航天、医疗和一点消费

周五不是所有板块都难看。

相对强势的方向也很清楚：

| 周五强势方向 |    涨幅 |
| ------------ | ------: |
| 航天装备     | +10.36% |
| 医疗研发外包 |  +7.11% |
| 院线         |  +6.72% |
| 航海装备     |  +6.30% |
| 风电整机     |  +6.27% |
| 医疗服务     |  +5.68% |
| 国防军工     |  +3.43% |
| 卫星互联网   |  +3.39% |
| 航天航空     |  +3.17% |

这里面有两条线。

第一条，是军工航天。

这和前面长征十号、可回收火箭、商业航天这些催化有关，也和周五市场高低切有关。科技主线太挤，资金就找同样有“硬科技味道”、但没那么拥挤的方向。

第二条，是医药医疗。

CRO、创新药、医疗服务走强，本质上是资金在科技大波动时找“相对低位 + 有业绩想象”的地方避一避。

注意，这不是说科技结束、医药接管。

更像是市场在说：

“科技我还喜欢，但你太吵了，我先去隔壁安静一会儿。”

## 三、券商和机器人：这次别硬写成主线

这里要特别说一下券商和机器人。

券商周四有中报业绩预期，逻辑不是没有。但周五证券板块跌 `1.88%`，主力资金净流出约 `24亿元`。

所以不能写成“券商启动”。

更准确是：

**券商有潜在指数修复逻辑，但盘面暂时没认可。**

机器人也类似。

前面一直有产业催化，有宇树、有具身智能、有各种小作文。但最近盘面一直很拧巴，周末也没有看到足够硬的全板块催化。

所以机器人现在不能靠“有新闻”就硬说主线。

市场已经不是以前那个纯情少年了。

以前听到“机器人”三个字就上头。

现在会问：“订单呢？利润呢？客户是谁？别只给我看PPT。”

## 四、美股给了科技一点底气，但不是免死金牌

再看外盘。

7月10日美股小幅收涨，标普500涨约 `0.4%`，纳指涨约 `0.3%`，道指涨约 `0.3%`。周度看，纳指涨约 `1.7%`，科技仍然比传统蓝筹强。

更关键的是结构。

SK海力士ADR在纳斯达克首日大涨约 `13%`，英伟达涨约 `4%`。这说明海外市场仍然在交易两条线：

一条是AI算力，一条是存储周期。

这对A股当然是加分项。因为A股周末最热的新闻，刚好也是存储和算力。

但美股也不是“科技全员发红包”。美光、英特尔等也有分化，说明海外资金同样在挑公司、挑业绩、挑确定性。

所以美股给A股科技的信号**不是：“兄弟们，闭眼冲。”而是：“方向还在，但别买错人。”**

## 五、周末消息面：主菜是存储和算力，辣椒油是油气军工

周末新闻很多，但真正能影响周一盘面的，我觉得就几类。

### 1. 国常会：加快新一代通信网、算力网建设

这条对科技方向是正催化。它直接对应算力、通信设备、光模块、服务器、数据中心、国产软硬件。

和周四的科技反攻、周五的科技调整连起来看，这条消息会让资金重新思考：科技是不是跌过头了？

但注意，政策催化不是万能药。它能修复情绪，但不能替公司交业绩。

### 2. 存储芯片：价格上涨 + 长鑫科技申购

这是周末最硬的产业线。

研究机构提到HBM价格预计2027年继续上行，存储涨价潮还在；同时长鑫科技下周申购，拟募资 `295亿元`，市场关注度很高。这会直接刺激A股存储、HBM、半导体材料、先进封装、设备链条。

问题是，周五存储芯片刚跌 `3.34%`，主力资金还净流出约 `217亿元`。所以周一存储很可能会被资金重点盯。

但重点不是“能不能高开”，而是：**高开以后有没有人接。**高开高走，说明周五是洗澡。高开低走，说明周五只是第一集。

### 3. 霍尔木兹：油气、航运、军工有事件脉冲

伊朗革命卫队称霍尔木兹海峡暂时关闭，这对原油、航运、黄金、军工都有刺激。

这类消息很容易让油气和军工在周一有表现。但它的问题也很明显：它是事件驱动，持续性看后续局势。

如果周一盘前缓和，行情可能开盘就降温。如果继续升级，那油气、黄金、军工会继续有脉冲。

这条线像辣椒油。够刺激，但不能当主食。

### 4. 中医药和氦气出口管制：有题材，但偏支线

中医药“十五五”规划、氦气临时禁止出口管理，都有对应板块。

但它们更像局部题材。能不能走出来，要看周一资金有没有从高位科技里切出来，去找低位政策题材。如果市场整体风险偏好修复，资金大概率还是先回科技。如果科技高开低走，支线题材才更容易轮动。



## 六、我的判断：明天大概率有修复，但别把反弹当反转

综合来看，我更倾向于：

**周一A股会有科技修复冲动，但盘中分化会很大。**

原因很简单。

利好确实有：

- 美股科技还在强势区间
- 英伟达和SK海力士给AI/存储打了气
- 国常会提到通信网、算力网
- 存储涨价和长鑫科技申购继续发酵

但压力也很实在：

- 周五科技主线大幅杀跌
- 半导体、存储、电子主力资金流出明显
- 中报预告窗口临近，市场开始要业绩
- 霍尔木兹和油价扰动可能压制高估值风险偏好

所以明天最好的走势，不是科技一开盘全线狂飙。

最好的走势是：**科技别急，先站稳。**

存储和算力能修复，指数不继续破位，低位军工、医药、油气有序轮动，这样市场反而健康。

最怕的是：高开十分钟，老师傅们集体开始派发盒饭。



> **明天A股的重点，不是科技能不能高开，而是高开之后，谁还愿意买单。**
